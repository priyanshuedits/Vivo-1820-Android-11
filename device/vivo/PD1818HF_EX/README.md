Starter device tree for an Android 11 ROM project.

- Device: vivo 1820
- Codename: PD1818HF_EX
- Board: k62v1_64_bsp
- SoC: MediaTek MT6765
- Target: Android 11

## Status
This is a starter tree adapted from the available recovery/TWRP tree. It is **not yet a complete or guaranteed-bootable Android 11 ROM tree**.

Still required:
- Android 11-compatible vendor blobs
- matching kernel source/config or validated prebuilt kernel
- HALs / proprietary interfaces
- sepolicy
- verified partition / AVB configuration
- device testing on real hardware

Do not flash this tree as a ROM by itself.
